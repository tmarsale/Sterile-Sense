# Sterile Sense AI: FMEA Review Workspace (prototype)

A React + Vite app that runs entirely in the browser: no backend, no database, and no AI API calls. It loads the illustrative sample FMEAs from `../data`. See `../PLAN.md` for scope and `../data/README.md` for data assumptions.

## Run it

```bash
cd app
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).
